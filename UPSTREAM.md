# Upstream provenance

This directory began as a clean-room restructuring of source retrieved from
[pskd73/flow32](https://github.com/pskd73/flow32). The current tree has since
been substantially reorganized around explicit hardware ownership, bounded
retained UI, host tests, and application-supplied adapters.

The retrieved upstream repository did not contain a project-level license at
the time of import. Third-party font/icon assets retain their own notices in
`licenses/`, but those notices do not grant a license for all framework source.

Before public redistribution, obtain or confirm an appropriate license from the
upstream copyright holder. `library.json` deliberately uses `NOASSERTION` until
that is resolved.
